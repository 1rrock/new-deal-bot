# New Coin Detection Trading Bot

업비트 신규 상장 코인을 자동으로 감지하고 시장가 매수 후 지정가 매도하는 트레이딩 봇.

## 기능

- 1.5초마다 업비트 전체 코인 리스트 조회
- 이전 리스트와 비교해 신규 상장 코인 감지
- 신규 코인 시 시장가 매수 (잔고 50%, 수수료 0.139% 고려)
- 매수 체결 후 매수가의 +2.4%로 지정가 매도 주문 등록

## 설치

1. Python 3.9+ 설치
2. 의존성 설치: `pip install -r requirements.txt`
3. `.env` 파일에 API 키 설정:
   ```
   UPBIT_ACCESS_KEY=your_access_key
   UPBIT_SECRET_KEY=your_secret_key
   DRY_RUN=true  # 테스트 모드
   ```

## 실행

```bash
python bot.py
```

## 전략 설명

- **예상 시나리오**: 신규 코인 상장 → 감지 → 잔고 50% (수수료 0.139% 고려)로 매수 → +2.4% 상승 시 수익 실현.
- **최악 시나리오**: 가격 상승 안 하면 주문 체결되지 않음. 하지만 신규 코인은 변동성으로 인해 결국 상승한다고 가정.
- **리스크**: 가격 하락 시 손실 가능. 한 달 10번 이내 거래로 규제 위반/제한 없음.

## 주의

실제 거래 시 자산 손실 가능성 있음. 테스트 후 사용.
